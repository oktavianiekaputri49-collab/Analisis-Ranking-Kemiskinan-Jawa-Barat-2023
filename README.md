# Analisis-Ranking-Kemiskinan-Jawa-Barat-2023
Project ini membahas analisis statistik data kemiskinan kabupaten/kota di Jawa Barat tahun 2023 berdasarkan persentase kemiskinan dan ranking daerah menggunakan data dari Badan Pusat Statistik (BPS). Analisis dilakukan untuk melihat distribusi tingkat kemiskinan serta perbedaan kondisi antar wilayah.
